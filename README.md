# howto_student_project
This repo has been created with the best intentions to provide:
(1) Hints on how to perform and report a scientific sound project, e.g. thesis project 
(2) LaTeX template 

# What is the goal?

# General Hints
- use overleaf for Latex and you do not need to set anything up
- try google colab for computations
- Time and Project management hints

# DO NOT PLAGIARISE aka credit where credit is due
you may use data, code, images, and even text from others IF and only IF:
(1) you refer to it properly! (e.g. on github there is often a license agreement and required citations)
(2) Do not display, distribute, copy data from others without their consent! (GDPR)
